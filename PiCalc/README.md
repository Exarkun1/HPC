# Задание
### Расчёт числа Pi
**Задача:** реализовать алгоритм вычисления числа Pi методом Монте-Карло  
**Язык:** C++ или Python  
**Входные данные:** количество точек N  
**Выходные данные:** время выполнения и полученные числа Pi  


# Описание проделанной работы
Данная лабораторная работа была выполнена на языке C++.

Эксперимент проводится на случайно сгенерированных данных в области (0, 0) - (1, 1), и результаты времени выполнения сравниваются между CPU и GPU для разного числа точек. 

**CPU:** функция `pi_calc_cpu` вычисляет число Pi методом Монте-Карло, где для заданного количества точек N генерируются случайные координаты x и y, проверяется попадание точки в единичный круг, и если точка внутри круга, счётчик увеличивается, далее по формуле `Pi=4⋅доля точек внутри круга`, рассчитывается приближённое значение Pi.

**GPU:** в функции `pi_calc_gpu` реализовано параллельное вычисление числа Pi с использованием технологии CUDA. Первоначально в функции создается массив `hints`, в котором будут храниться количество отсчетов, попавших в единичную область, полученных каждым блоком потоков. Далее вызывается функция ядра `pi_calc_kernel`, где каждый поток сначала подсчитывает количество попаданий точек в область (делим между потоками число точек поровну). Происходит суммирование отсчетов внутри блока потоков путем редукции с дальнейшим сохранением в массив `hints`. После окончания вычислений на GPU отсчеты полученные блоками суммируются на CPU.

Как видно из таблицы, при малом N последовательный алгоритм работает быстрее, что объясняется накладными расходами на передачу данных и поддержание потоков, но уже при **N=2097152** параллельный алгоритм имеет меньшее время выполнения чем последовательный.
